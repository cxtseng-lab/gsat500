學測英文 500 單字 App（PWA）

【直接使用】
雙擊 index.html 就能在瀏覽器中開啟（可離線使用，但無法「安裝」）。

【安裝到手機主畫面】PWA 需要放在 https 網址上：
1. 到 GitHub 建立一個新的 repository，把本資料夾所有檔案上傳。
2. 在 Settings → Pages 選擇 main 分支並儲存，就會得到 https://你的帳號.github.io/repo名稱/ 網址。
   （也可以改用 Netlify Drop：把整個資料夾拖進 app.netlify.com/drop。）
3. 手機打開該網址：
   - iPhone（Safari）：分享 → 加入主畫面
   - Android（Chrome）：選單 → 安裝應用程式 / 加到主畫面
4. 安裝後即可像 App 一樣全螢幕開啟，並支援離線使用。

熟悉度與錯題本儲存在該裝置的瀏覽器中，不會同步到其他裝置。
